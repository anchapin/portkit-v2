# Bedrock reference: sources and attribution

`bedrock_reference.json` is generated by `scripts/build_bedrock_reference.py`
from the pinned commits below. Do not edit it by hand: change the script and
rerun it (`python scripts/build_bedrock_reference.py --check` tells you whether
the committed file is current). The `lookup_bedrock` tool reads it together with
the Mojang schemas vendored under `portkit/validate/schemas/` (MIT, see
`validate/schemas/SOURCE.md`).

## Attribution (CC-BY-4.0)

Portions of `bedrock_reference.json` (the `summary`, `fields`, `tags` and most
`example` values whose `sources` entry names `MicrosoftDocs/minecraft-creator`)
are adapted from the Minecraft Creator documentation, (c) Microsoft
Corporation, licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Changes: text cut to
the first paragraph, property tables flattened into one line per property and
shortened, code blocks re-indented. Every lookup result carries its sources so
the attribution travels with the excerpt.

## Mojang samples

The vanilla excerpts are a few hundred bytes each, kept as reference examples of
the file formats an add-on must use. They are not redistributed as a pack, and
the upstream licence statement above applies to them.

## Notes

The `note` values are portkit's own, written for the residue agent: what
portkit's validator checks and the mistakes worth avoiding.
